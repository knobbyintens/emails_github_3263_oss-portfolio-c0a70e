# Larkspur Open Source Program — Project Portfolio

This repository backs the public showcase for the Larkspur Open Source Program.
Each project has a page under `projects/` with front matter describing its
track, brief and current program stage.

## Program stages

- `Internal Review` — a public release proposal is being reviewed by the board.
- `Incubation` — an early project that has not yet been proposed for release.
- `Public Release` — approved and distributed publicly.
- `Archived` — retired or not approved for public release.

## Repository conventions

- Project pages live at `projects/<project-slug>.md`.
- Support code for a project lives in a separate repository whose name includes
  the project slug. Only repositories whose `RELEASE.md` explicitly declares a
  public release may be linked from a project page.

Keep the showcase repository limited to approved public material.
